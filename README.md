### Installation


For Linux/Mac OS:
```
curl -sSL https://raw.githubusercontent.com/alden4444/pattern_pc_compliance_audit/main/Pattern_PC_Compliance_Audit.py -o /tmp/audit.py && python3 /tmp/audit.py
```

For Windows (PowerShell as admin):
```
irm https://raw.githubusercontent.com/alden4444/pattern_pc_compliance_audit/main/Pattern_PC_Compliance_Audit.py -OutFile "$env:TEMP\audit.py"; python "$env:TEMP\audit.py"
```
